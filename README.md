# SSCP Study Resources

Material and resources for pursuing SSCP (Systems Security Certified Practitioner) certification — built from (ISC)²'s current SSCP Certification Exam Outline (effective October 1, 2025), current as of September 2026.

## A note on currency

The current outline stems from a **Job Task Analysis refresh that took effect September 15, 2024**, with a minor administrative re-issue dated October 1, 2025 (no domain/weight changes between those two dates). The most visible 2024 change was a **rename of Domain 1** from "Security Operations and Administration" to **"Security Concepts and Practices"** — if a study resource still uses the old Domain 1 name, it predates the refresh. ISC2 has also woven explicit AI-related guidance into every domain's current outline description (e.g., securing AI agent identities in Domain 2, detecting "model drift" in Domain 3, forensics on AI system logs in Domain 4) — reflected below wherever it appears in the official outline.

## Overview

- **Who is it for?** SSCP is (ISC)²'s hands-on practitioner credential — aimed at security administrators, analysts, and engineers who implement, monitor, and administer IT infrastructure day to day, sitting a level below CISSP's management/architecture focus. ISC2 markets it as "The Premier Security Administrator Certification."
- **Experience requirement**: just **1 year** of cumulative paid work experience in one or more of the seven domains (versus CISSP's 5 years across 2+ domains) — a relevant degree can satisfy up to 1 year of that requirement. Candidates without the experience can earn Associate of ISC2 status and have 2 years to complete it.
- **Exam format**: 125 questions, 3 hours, multiple choice plus advanced item types, scaled passing score of 700 out of 1000. Available in English, Japanese, and Spanish.
- **Domain weights (effective September 15, 2024 / re-issued October 1, 2025):**

| Domain | Weight |
|---|---|
| 1. Security Concepts and Practices | 16% |
| 2. Access Controls | 15% |
| 3. Risk Identification, Monitoring and Analysis | 15% |
| 4. Incident Response and Recovery | 14% |
| 5. Cryptography | 13% |
| 6. Network and Communications Security | 16% |
| 7. Systems and Application Security | 11% |

- **Test-taking strategies**
  - Questions are written to test *operational application* of security knowledge (selecting the correct access control mechanism for a described scenario, choosing the right incident response step) rather than pure theory recall — think like the administrator actually doing the work, not just the person writing the policy
  - Domains 1 and 6 are jointly the heaviest (16% each) — don't under-invest in networking fundamentals if your background is more administrative than technical, or vice versa
  - SSCP overlaps heavily with CISSP's Domains 3, 4, 5, and 7 content at a more hands-on/operational depth — if you've studied CISSP, treat this as applying that knowledge at the implementation level rather than relearning from scratch
